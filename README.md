# Dutch Trainer

A personal app for practising Dutch grammar alongside a course: inversion, separable verbs,
want/omdat/daarom, adjective endings, telling time, and more. Exercises are generated by code,
so every answer is checked by a rule rather than a fixed answer list.

**Live:** https://csabattilas.github.io/dutch/

Personal learning project, provided as is: it may contain mistakes. No cookies, no tracking;
progress is stored only in your browser.

## Layout

```
dutch-app/   Angular app (PWA-ready, works offline on a tablet)
tools/       build-time data scripts (Node, no dependencies), see tools/README.md
data-raw/    downloaded source datasets (not in git)
```

## Develop

```bash
cd dutch-app && npm install && npm start
```

Tests: `npx ng test --watch=false` in `dutch-app/`, `npm test` in `tools/`.
Pushing to `main` tests, builds and deploys to GitHub Pages (`.github/workflows/deploy.yml`).
